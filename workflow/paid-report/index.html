유료 리포트

무료 MVP(①~⑧)는 경보를 확정해서 보여주는 데까지다. 유료 리포트는 그 경보를 고객사 실제 공급망과 연결해, 대체공급국·지원정책까지 한 장으로 묶어 발행한다.

아래 구성은 기획 중인 유료 리포트의 목차이자, 각 항목을 무엇으로 채울지의 근거다. 실제 발행 자동화는 아직 없고, 대체공급처·지원정책 페이지에서 지금 가진 데이터로 무엇을 보여줄 수 있는지 확인할 수 있다.

리포트 구성

각 섹션이 무엇을 근거로 채워지는지 함께 표시한다

1. 경보 요약

확정된 Yes 경보의 사건 내용, 영향국, 관련 HS6·발생 시각을 한 장으로 정리한다.

근거 데이터 · ①~⑧ 무료 MVP 파이프라인 결과 그대로 사용

2. 노출도 · 심각도

HHI(수입 집중도)·통관 스파이크를 참고 지표로 함께 보여줘, 같은 Yes 경보라도 얼마나 심각한지 가늠하게 한다.

근거 데이터 · TRASS 15개월 시계열(⑦⑧) — 379개 확보완료 품목 기준, 나머지는 HS4참고치

3. 고객 노출 결합

고객사가 실제로 수입하는 HS6·공급국을 사건 영향국과 겹쳐, "내 회사에 영향이 있는 경보만" 남긴다.

근거 데이터 · ⑨ 고객 노출 결합 — 유료 범위, 고객별 HS6 등록 필요

4. 대체공급국 후보

영향국을 제외하고, 같은 HS6를 실제로 수출 중인 국가를 수입 비중 순으로 추천한다.

근거 데이터 · customs_alternatives.json(관세청 수출입통계) · comtrade_alts.json(UN Comtrade 기반, 현재 10개 우선품목)

5. 지원정책·네트워크 연계

대체공급국에 KOTRA 해외 법인·사무소가 있는지, 공급망 전환에 쓸 수 있는 정부·기관 지원정책이 있는지 매칭한다.

근거 데이터 · kotra_map.json(9,927개 법인·84개국) — 지원정책 자격요건 필터는 후속 구축

발행 방식 (기획)

  • 발행 주기. 확정된 Yes 경보가 고객 등록 HS6·공급국과 겹칠 때마다 건별로 발행한다 — 정기 리포트가 아니라 이벤트 트리거 방식.
  • 형식. 웹에서 바로 보는 대시보드 + PDF 다운로드를 함께 제공한다(기획 단계, 자동 PDF 생성은 미구현).
  • 데이터 정밀도 표기. 품목 커버리지 검색에서 쓰는 "HS6실측 / HS4참고" 구분을 리포트에도 그대로 노출해, 어떤 근거가 더 정밀한지 고객이 알 수 있게 한다.
