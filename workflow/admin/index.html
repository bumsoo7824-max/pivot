핵심 교훈

  • ·같은 데이터로 사전을 넓히면 숫자는 좋아 보이지만 거짓 개선 — 라운드2(86%)→라운드3 held-out(47%)에서 확인. 항상 held-out으로 검증.
  • ·정확 문구 추가보다 구조적 규칙이 더 잘 일반화됨 — 행위어근+무역어 공존조건 하나로 47%→87%, 학습셋 성능은 그대로.
  • ·시뮬레이션과 실 API 결과는 다르다 — 87%(로컬)→53%(실데이터)에서 20%p+ 격차. 반드시 실 API로 재검증.
  • ·소스가 많다고 항상 좋은 건 아니다 — 유명 사건 세트(라운드11)에서는 결합 효과 0%p였지만, 진짜 과녁 사건(라운드12)에서는 +6%p 실익 확인.
  • ·미탐 원인은 하나가 아니다 — 창(window) 문제, 진짜 키워드 갭, 구조적 보도 공백, ref_date 추정 오류를 매번 구분해야 함.
  • ·'유명한 세계 뉴스'를 잡는 성능(67~83%)과 '우리 제품이 실제로 신경써야 할 사건'을 잡는 성능(47~53%)은 전혀 다른 숫자 — 발표에서 재현율을 말할 땐 반드시 어떤 사건 기준인지 명시.
