사전 판정에서 경보 발행까지 — ⑤~⑧ 상세

뉴스 사건이 HS6·국가에 매핑된 뒤, classify()가 자동으로 방향을 점검하고, 신호등 3단계를 거쳐, 노출도(HHI)와 통관 지표로 심각도를 붙이기까지의 과정.

⑤ classify() 사전 판정 (자동)

사람이 직접 읽지 않고 제목+발췌만으로 1차 방향을 자동 점검한다.

2026-09-25 확정 사전. MATERIALS_TIER2를 관세청 공식 품목명 기준 전체 유니버스(1,109개 hs6/256개 HS4)로 확장 완료.

DISRUPT (차질 신호)

수출금지·통제·파업·불가항력 등 공급이 흔들렸다는 사건 언어. ACTION_ROOT(행위어근)와 TRADE_WORD(무역어)가 공존하면 정확한 어순이 아니어도 신호로 인정한다.

MATERIALS (품목 신호)

관세청 HS부호단위별품목명 공식자료 전체 유니버스(HS4 256 / HS6 1,109)를 Kiwi 형태소분석기로 정제해 만든 MATERIALS_TIER2(1,078개)를 병합 — 총 1,229개.

⑥ 신호등 3단계

Yes 판정도 사람이 직접 확인한 뒤에만 발행된다 — 자동 발행 단계는 없음.

Yes (RELEVANT)

차질 신호 + 품목 신호가 둘 다 걸린 명확한 사건. 사람이 직접 검토·확정 후 다음날 09시 발행.

CANDIDATE

사건 언어는 있는데 사전에 없는 표현이라 품목어가 안 걸린 절충안 구간. LLM이 구조화 요약(관련여부·추정 HS6·확신도·판단근거)을 만들면 사람이 최종 검토한다.

No (NONE)

차질/품목 신호가 모두 없는 무관 기사. 조용히 버려지며 사람 검토 대상이 아니다.

CANDIDATE는 classify()가 설계상 의도한 절충안 구간(사건언어 O, 품목어 X) — LLM이 구조화 요약(관련여부/추정HS6/확신도/판단근거) 생성 후 사람이 최종 검토. Yes 판정도 자동 발행하지 않고 사람이 직접 확인 후 발행. 사람 검토 후 새 키워드 확인되면 discover_candidates.csv를 통해 ②·⑤ 사전으로 피드백.

⑦ 노출도(HHI·수입비중) 1차 심각도

2026-09-25 결정: 참고용 지표로 다운그레이드

HHI는 과거 세션 논문 검토에서 판정력이 크지 않다고 확인됨 — 핵심 판정은 사건 소급용 뉴스(②~⑥). 552개 사각지대의 HHI 전량 계산은 필수 아님, 시간이 오래 걸리면 건너뛰어도 됨.

HHI(허핀달-허쉬만지수)는 과거 세션 논문 검토(스파이크 P=0.45, 단가 P=0.50, HS6 좁힘 P=0.588 n=45 비유의)에서 판정력이 크지 않다고 확인됐다. 552개 사각지대의 HHI 전량 계산은 필수가 아니며, 핵심 판정은 여전히 ②~⑥ 뉴스 소급이다.

⑧ 통관 스파이크 · 단가 · 물량

확인/심각도(소급용) — 신호등 판정 자체를 바꾸지 않는다

신호등 판정 자체는 바꾸지 않음. 참고 지표.

관세청 통관 통계는 익월 중순에야 확정되므로(골든타임 참고), 뉴스 경보가 나간 지 3~4개월 뒤 "실제로 수치에도 찍혔는지"를 소급 확인하는 사후 검증 지표다.

CANDIDATE 검토 → 사전 피드백 루프

사람이 CANDIDATE를 검토하다 새 키워드(사전에 없던 사건어·품목어)를 확인하면 discover_candidates.csv를 통해 ②·⑤단계 사전으로 다시 피드백한다 — 이 루프가 있어 "처음 보는 표현으로 보도되는 새 사건"에 대한 안전망이 된다.
