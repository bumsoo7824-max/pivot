    전체 유니버스 1,109개 hs6(256 HS4) 중 379개만 대체공급처까지 파이프라인에 실제 연결됨. 2026-09-26 nitemtrade API 보완 수집(계정 3개 분산 22,080콜)으로 원래 552개 사각지대 중 543개는 12개월(2025.09~2026.08) 수입액·최대 공급국을 확보했으나 아직 최종 리스크 테이블(HHI·대체공급국 매칭)에는 미반영 — 대체공급국 후보 확인용 참고 데이터. 9개는 nitemtrade로도 수입 미확인이라 여전히 진짜 사각지대. 170개(52HS4 그룹)는 TRASS 수집은 됐지만 최종 리스크 테이블에는 아직 미반영, 8개는 15개월간 거래 자체가 없음.

  6. 06완료

    신호등 3단계

    자세히 ›

    Yes(RELEVANT) / CANDIDATE / No(NONE)

    CANDIDATE는 classify()가 설계상 의도한 절충안 구간(사건언어 O, 품목어 X) — LLM이 구조화 요약(관련여부/추정HS6/확신도/판단근거) 생성 후 사람이 최종 검토. Yes 판정도 자동 발행하지 않고 사람이 직접 확인 후 발행. 사람 검토 후 새 키워드 확인되면 discover_candidates.csv를 통해 ②·⑤ 사전으로 피드백.

    노출도(HHI·수입비중) 1차 심각도

    자세히 ›

    2026-09-25 결정: 참고용 지표로 다운그레이드
